# Real-world decks for the Rendered tab tests

`node tests/render.mjs` runs the scene-model and renderer checks on **every `.pptx` in this folder** (and on any file listed in
`REAL_PPTX=/path/a.pptx:/path/b.pptx`). The checks are file-agnostic, so you can drop in your own decks:

- nothing may be silently dropped (every shape element in the XML is in the scene model or listed as unplaced),
- stable, unique element ids and document-order z-order,
- the XML is not changed by reading it,
- every element is drawn natively, drawn approximately (with a reason), or shown as an opaque placeholder; never skipped.

## What is in here, and what is not

| File | Provenance |
|---|---|
| `ppt-default-english.pptx`, `ppt-default-arabic-rtl.pptx` | Master, layouts and theme from python-pptx's bundled `default.pptx`, which was authored in **Microsoft PowerPoint** (python-pptx is MIT licensed). The slides on top are generated by `tests/make_real_p31.py`. |
| `lo-*.pptx` | The Phase 3.1 fixtures re-saved by **LibreOffice Impress**. Every XML part is written by LibreOffice's exporter, a different writer from python-pptx. `lo-arabic.pptx` carries RTL paragraphs exported by LibreOffice. |

**Not available when this set was built (no network access):** decks exported by PowerPoint itself, Keynote or Google Slides, and the FOOD deck.
Those are still the largest unknown. Please add a few (an Arabic RTL deck from PowerPoint, one from Google Slides, one from Keynote) and run the tests.
